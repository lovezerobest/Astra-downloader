# AstraDownloader（星流下载器）

一个基于 **Astraland（星河岛）** 的 Android 网盘解析 + 多线程下载插件。

复制/粘贴网盘分享链接或任意直链，应用自动识别并弹出星河岛流体云卡片，点「下载」即可多线程分片下载，进度实时同步到岛卡片。

---

## 功能特性

- **链接自动识别**：识别夸克 / UC / 百度 / 139和彩云 / 123云盘 / 迅雷 分享链接，以及任意 http(s) 直链。
- **多线程分片下载**：Range 分片并发 + 断点续传，线程数可在设置调整（最大 64）。
- **美团盘解析**：登录对应网盘后，分享链接自动解析出下载直链。
- **星河岛卡片**：识别链接 → 展开流体云卡片（带「下载 / 停止」按钮）→ 实时进度同步。
- **剪贴板自动识别**：前台服务常驻监听剪贴板，复制链接自动投递岛卡片。
- **MIUI 风格界面**：纯 Compose 实现的 MIUI 观感（品牌蓝、圆角卡片）。
- **下载管理页**：任务列表，支持暂停 / 继续 / 删除 / 打开。

## 架构分层
```
---
### 链接识别与岛卡片

```
复制链接(前台页面/前台服务；后台受 Android 限制) ─► LinkResolver.resolve
                         ├─► Share(网盘) ─► 异步预解析直链 ─► 更新岛卡片「下载/停止」
                         └─► Direct(直链) ─► 岛卡片「下载/停止」
```

### 网盘解析下载

```
复制分享链接 → 登录校验、解析分享（createSession → listFiles → 取下载直链）
点岛卡片「下载」→ 复用预解析结果（仍在解析则等待；失败可重试）
  └─► DownloadManager.enqueue ✔ 开始分片下载
```

### 进度同步到岛

```
DownloadManager.onProgress
  └─► 主线程 → IslandBridge.updateDownloadProgress(cardId, ...)
        └─► island.start() 更新同一卡片 id 的 PROGRESS 模板
```

### 结束 / 停止

```
下载完成 ─► COMPLETED ─► 归位100% ─► end(outro: "下载完成") 卡片消失
点「停止」─► cancel 任务 ─► end(cardId) 收起岛卡片
```
## 已知限制 / 说明

- **后台剪贴板监听受限**：系统限制后台应用读取剪贴板；前台服务不保证能读取其它应用中的复制内容。复制后回到本应用会检查剪贴板；本应用前台期间复制可即时识别。
- **下载进度偶有停滞**：部分体积/网络下，进度可能停在 ~92%~99%（网络层挂起导致未触发完成判定），为已知待优化点。
- **支持平台登录**：夸克 / UC / 百度 / 139 走 WebView 登录；123 / 迅雷登录页尚未完成。
- **仅主用户空间**。
